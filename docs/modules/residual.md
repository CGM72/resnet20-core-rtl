정렬된 main과 skip을 더하고 INT16 범위로 포화한다. 서로 다른 위치/채널을 맞춰 주는 기능은 포함하지 않는다.

```text
E0: 부호 확장 → 합산 → 포화 → pending_data / E1: out_data
```

표의 비트 수·상수 값은 기본 파라미터 기준입니다. `parameter`는 외부 설정, `localparam`은 내부에서 정해지는 상수입니다.
E0은 입력 수신 상승 에지이며, 출력 시점은 해당 에지의 레지스터 갱신 직후입니다.

## 1. 모듈 `residual`

### 1.1 설정 파라미터

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `BITWIDTH` | parameter / 기본 16 | 입력·출력 데이터 한 개의 비트 수. 기본 signed INT16 범위를 사용한다. |

### 1.2 입출력 포트

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `clk` | input / 1비트 | 데이터를 수신하고 순차 상태를 갱신하는 상승 에지 클럭. |
| `nrst` | input / 1비트 | 0이면 비동기 reset. 유효 표시와 해당 모듈의 상태를 초기화해 진행 중인 계산을 취소한다. |
| `enable` | input / 1비트 | 블록 기능 선택. 1은 연산, 0은 입력을 같은 단계 수로 우회. 입력 유효 표시와는 다르다. |
| `in_enable` | input / 1비트 | 현재 상승 에지에 in_data가 유효하다는 표시. 0인 클럭은 새 입력으로 세지 않는다. |
| `in_data` | input / 16비트 signed | 처리할 입력 한 개. 기본 Q5.10 저장 정수이며, 유효할 때만 연산에 사용한다. |
| `skip_data` | input / 16비트 signed | main 입력과 같은 위치·채널·Q scale의 잔차 값. 정렬은 core 또는 외부가 담당한다. |
| `out_enable` | output / 1비트 | 현재 출력 데이터가 유효하다는 표시. 연속 결과이면 여러 클럭 연속 1일 수 있다. |
| `out_data` | output / 16비트 signed 레지스터 | main+skip의 포화 합 또는 우회 값. 입력 E0에서 계산해 E1 직후 출력한다. |

### 1.3 내부 폭·상수

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `WORD_W` | localparam / 값 16 | 입출력 데이터 폭 BITWIDTH의 내부 이름. |
| `SUM_W` | localparam / 값 17 | 덧셈 결과 폭. 두 INT16 합의 overflow를 보존하기 위해 한 비트 늘린다. |
| `SAT_MAX` | localparam / signed 17비트, 값 32767 | 출력이 표현할 수 있는 양수 상한. |
| `SAT_MIN` | localparam / signed 17비트, 값 -32768 | 출력이 표현할 수 있는 음수 하한. |

### 1.4 내부 데이터·상태·연결 신호

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `pending_enable` | reg / 1비트 | E0 입력 valid를 저장하고 다음 에지 out_enable로 전달한다. |
| `pending_data` | reg / signed 16비트 | E0에서 계산한 포화 합 또는 우회 값. E1에 out_data로 전달한다. |
| `main_ext` | wire / signed 17비트 | in_data를 한 비트 부호 확장한 값. |
| `skip_ext` | wire / signed 17비트 | skip_data를 한 비트 부호 확장한 값. main_ext와 더한다. |

## 2. 함수 `saturate()`의 인자·지역 변수

함수 안의 `reg`는 조합 계산용 임시 변수이며 클럭 단계를 추가하지 않습니다. 표의 `함수명.변수`는 소속을 구분하는 표기입니다. 실제 소스 안에서는 변수 이름만 사용합니다.

반환값은 signed 16비트입니다. 함수 이름에 대입한 값이 호출부로 반환됩니다.

| 선언 이름 | 종류·기본 폭 | 역할 |
|---|---|---|
| `saturate.value` | 함수 인자 / signed 17비트, Q10 | main_ext+skip_ext의 합. -32768..32767로 제한한 16비트 값을 반환한다. |

## 3. 코드와 파형을 따라 읽는 예

저장 정수 1024+512→1536. 32760+20→32767로 포화한다. `pending_data`에서 계산 결과를 보고 다음 에지 `out_data`로 같은 값이 이동하는지 확인한다.

세부 실행 명령과 reset/입력 공백/포화 확인 순서는 상단의 파형 가이드를 따른다.
