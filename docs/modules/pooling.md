N개의 유효 입력 중 signed 최대값 하나를 만든다. 어떤 값들을 같은 창으로 묶을지, stride/주소를 어떻게 정할지는 외부가 맡는다.

```text
유효 입력 N개를 비교 → 마지막 항 E0: pending_data / E1: out_data
```

표의 비트 수·상수 값은 기본 파라미터 기준입니다. `parameter`는 외부 설정, `localparam`은 내부에서 정해지는 상수입니다.
E0은 입력 수신 상승 에지이며, 출력 시점은 해당 에지의 레지스터 갱신 직후입니다.

## 모듈 `pooling`

### 설정 파라미터

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `BITWIDTH` | parameter / 기본 16 | 입력·출력 데이터 한 개의 비트 수. 기본 signed INT16 범위를 사용한다. |
| `BITWIDTH_POOLING_ITERATION` | parameter / 기본 16 | MaxPool 창에 모을 데이터 개수와 카운터의 폭. |

### 입출력 포트

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `clk` | input / 1비트 | 데이터를 수신하고 순차 상태를 갱신하는 상승 에지 클럭. |
| `nrst` | input / 1비트 | 0이면 비동기 reset. 유효 표시와 해당 모듈의 상태를 초기화해 진행 중인 계산을 취소한다. |
| `enable` | input / 1비트 | 블록 기능 선택. 1은 연산, 0은 입력을 같은 단계 수로 우회. 입력 유효 표시와는 다르다. |
| `in_enable` | input / 1비트 | 현재 상승 에지에 in_data가 유효하다는 표시. 0인 클럭은 새 입력으로 세지 않는다. |
| `iteration` | input / 16비트 unsigned | 그룹당 유효 입력 수 N. 활성 상태의 0은 입력을 폐기하고 부분 그룹을 초기화한다. |
| `in_data` | input / 16비트 signed | 처리할 입력 한 개. 기본 Q5.10 저장 정수이며, 유효할 때만 연산에 사용한다. |
| `out_enable` | output / 1비트 | 현재 출력 데이터가 유효하다는 표시. 연속 결과이면 여러 클럭 연속 1일 수 있다. |
| `out_data` | output / 16비트 signed 레지스터 | N개 유효 입력 중 최대값. 마지막 입력 E0에서 계산해 E1 직후 출력한다. |

### 내부 데이터·상태·연결 신호

| 선언 이름 | 선언 종류·기본 폭/값 | 역할·갱신 시점 |
|---|---|---|
| `maximum` | reg / signed 16비트 | 현재 창에서 마지막 항 직전까지 모은 최대값. 첫 항으로 시작하고 창 완료 시 0으로 지운다. |
| `input_count` | reg / unsigned 16비트 | 현재 창에서 먼저 받은 유효 항 수. 공백에서는 유지하고 N번째 항 뒤 0으로 돌아간다. |
| `pending_enable` | reg / 1비트 | 창 완료 또는 우회 값의 유효 표시. 다음 에지 out_enable이 된다. |
| `pending_data` | reg / signed 16비트 | N번째 항까지 포함한 최대값 또는 우회 값. 마지막 항에서 maximum이 지워져도 이 값은 보존한다. |
| `next_maximum` | wire / signed 16비트 | 첫 항이면 in_data, 이후면 in_data와 maximum 중 큰 값. 현재 입력이 invalid이면 사용하지 않는다. |

## 코드와 파형을 따라 읽는 예

N=4에서 [-5,-2,-7,-9]→-2. 첫 항은 이전 `maximum`이 0이어도 -5로 새 창을 시작한다. 마지막 항 에지에는 `maximum`이 0으로 지워질 수 있으므로 결과는 `pending_data`에서 확인한다.

세부 실행 명령과 reset/입력 공백/포화 확인 순서는 상단의 파형 가이드를 따른다.
