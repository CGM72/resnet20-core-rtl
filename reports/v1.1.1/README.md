# 1.1.1 패치 검증과 리포트 상태

[SoC와 사용 전제](../../docs/SOC.md) · [패치 검증 상세](../../docs/PATCHES.md#111-가독성-패치와-동등성-검증) · [1.1.0 실측 원본](../v1.1.0/README.md)

1.1.1은 ZedBoard의 Zynq XC7Z020(`xc7z020clg484-1`)를 대상으로 한 1.1.0 가독성 패치입니다.
논리식·레지스터·속성·포트·신호명을 유지했고, 6개 RTL 토큰 일치와 기본 core 논리 동등성(828개 증명/미증명 0)을 확인했습니다.
기능 TB는 core 531개 출력 및 전체 ResNet-20의 22개 연산 레이어 기준값 비교를 통과했습니다.

| 자료 | 상태 |
|---|---|
| 1.1.0 post_route Timing/Utilization | 사용자 제공 원본 이미지와 수치 보존 |
| 1.1.1 RTL/기능 동등성 | 검증 완료 |
| 1.1.1 별도 Vivado post_route | 재실행하지 않음, 새 실측값 없음 |

참고 기준은 1.1.0의 10ns(100MHz) OOC 결과입니다. core WNS +2.716ns, LUT 609, FF 544, DSP 1입니다.
이 수치를 1.1.1의 새 측정 결과로 이름만 바꿔 게시하지 않습니다.
1.1.1에서 새 결과를 만들려면 다음 순서로 실행합니다.

```tcl
fpga::finish
fpga::analyze core
```

결과는 build/analysis/core/ 아래 새 실행 폴더에 저장됩니다.
기본 분석 제약과 실제 시스템 I/O·reset 제약의 범위는 [SoC 문서](../../docs/SOC.md)를 확인하십시오.
